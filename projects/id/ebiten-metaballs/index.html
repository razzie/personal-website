Ebiten Metaballs

Source code:
github.com/razzie/ebiten-metaballs

Year: 2026

Tags: golang rendering

Inspired by my metaball squeeze shader, I wanted to turn the effect into a reusable Go library for Ebitengine. Metaballs of the same color merge smoothly, while different groups squeeze against each other and rigid walls. There is also an optional soft body physics package to play with connected blobs.
