Ebiten Infinicave

Source code:
github.com/razzie/ebiten-infinicave

Year: 2026

Tags: golang rendering

I wanted to revisit my blob game concept and see if the new GPT6 Astra model could implement it based on an image, since I had problems doing this with AI in the past. It still took about 4 tries before I achieved something remotely resembling the concept. The result is a Go library for Ebitengine that generates an infinite cave with faceted rocks, branching vines and mushrooms, with an interactive viewer to scroll through the world and carve away terrain.
